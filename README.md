# Actividades de Aprendizaje de Programación

Bienvenido a esta colección de actividades diseñadas para aprender varios lenguajes de programación desde cero.

## 🎯 Objetivo

Este repositorio contiene una serie de actividades estructuradas para que puedas comenzar a aprender programación de manera práctica y progresiva.

## 📚 Lenguajes Incluidos

### 1. [Python](./actividades/python/README.md)
- Lenguaje ideal para principiantes
- Sintaxis clara y legible
- Ampliamente usado en ciencia de datos, web y automatización

### 2. [JavaScript](./actividades/javascript/README.md)
- El lenguaje de la web
- Esencial para desarrollo front-end
- También usado en back-end con Node.js

### 3. [Java](./actividades/java/README.md)
- Lenguaje orientado a objetos robusto
- Usado en aplicaciones empresariales
- Base para desarrollo Android

## 🚀 Cómo Empezar

1. Elige un lenguaje de programación que te interese
2. Sigue las actividades en orden (Básico → Intermedio → Avanzado)
3. Practica cada ejercicio hasta sentirte cómodo
4. No tengas miedo de experimentar y cometer errores

## 📖 Estructura de las Actividades

Cada lenguaje tiene actividades organizadas en tres niveles:

- **Nivel Básico**: Conceptos fundamentales y sintaxis
- **Nivel Intermedio**: Estructuras de datos y funciones
- **Nivel Avanzado**: Proyectos prácticos y conceptos avanzados

## 💡 Consejos para Aprender

- Practica todos los días, aunque sea 30 minutos
- Escribe el código tú mismo, no solo lo copies
- Experimenta modificando los ejemplos
- Busca ayuda cuando te atores
- Construye proyectos pequeños con lo que aprendes
